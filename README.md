# VEIN 配方查询表

废土生存游戏《VEIN》的中文离线查询表，单个 HTML 文件，双击就能打开，不用联网、不用装任何东西。

- 在线使用：https://x398746951.github.io/xiefeng/
- 下载：打开上面这个网址，点顶部「下载本表」；或者在 GitHub 仓库点右上角绿色 `Code` → `Download ZIP`，把整份拿走。

## 里面有什么

- 配方 1281 条：材料、工具、耗时、解锁条件，按物品栏分类
- 物品代码 759 条：控制台 `GiveItem` 直接刷东西用
- 秘籍 26 条、游戏攻略、武器、角色档案、技能速查
- 材料反查：有废铁×3 能做什么，差多少材料一目了然，支持 +1/+5/+10 改数量
- 浅色/暗色主题跟随系统自动切换，秘籍表和物品表列宽可拖拽

## 说明

数据和条目是自己边玩边核对着录的，配方以游戏内实测为准；游戏还在抢先体验阶段，版本更新后可能有变动。
