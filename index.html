工具等级

任何拆解、制作、建造、修理都需要工具，包括开罐头。工具向下兼容，越高级越省事，拿一个就行。液压工具用专用重型锂电池，其他用锂电池。

切割工具类
1级基本：剪刀/切肉刀/面包刀 → 2级重型：钢锯/断线钳/战斧 → 3级电动：圆锯/曲线锯 → 4级工业：研磨机 → 5级液压：液压切割机
钻类
1级电动：冲击钻 → 2级工业：工业钻（能换批头的电钻可当螺丝刀）→ 3级液压：液压驱动器
锤类
1级基本：羊角锤 → 2级重型：大锤/迷你大锤
钳子类
1级基本：活口钳/组合钳 → 2级重型：管钳/锁紧钳
螺丝刀类
1级基本：一字/十字 → 2级电动：电动螺丝刀 → 3级工业：工业钻 → 4级液压：液压驱动器
焊接类
1级基本：便携焊机/电烙铁 → 2级工业：工业焊机
钉类
1级基本：订书机 → 2级工业：钉枪 → 3级重型：重型钉枪
专用类
挖掘/挖矿/伐木：镐、改进型镐、铲子、斧头
